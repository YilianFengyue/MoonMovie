# MoonMovie 播放器内核升级方案（libmpv）

> v0.1 · 2026-10-02 · 状态：待确认
> 本文替代《设计方案》中"播放内核选 FlyleafLib，libmpv 备选"的结论，原因见第 2 节。

---

## 0. 一句话

把播放内核从系统自带的 Media Foundation 换成 **libmpv**。画面通过 D3D11 合成交换链挂到 WinUI 的 `SwapChainPanel` 上，界面、弹幕、控制栏照旧用 XAML 叠在上面。

换了以后能得到这些：

- 几乎所有格式都能放，高清硬解码；
- ASS 特效字幕；
- HDR；
- 补帧；
- Anime4K 等超分辨率；
- 完整的本地播放。

现有的界面、弹幕、选集和片源面板、去广告代理、续播都**保留**。

---

## 1. 目标与验收指标

| 指标 | 目标 |
|---|---|
| 首帧时间 | 本地文件 ≤ 0.8 s；网络片源 ≤ 2.5 s（从点击到出画面，不含片源搜索） |
| 拖动进度 | 本地 ≤ 300 ms；已缓存的网络分段 ≤ 500 ms |
| 切换下一集 | 预加载命中时 ≤ 1 s，片尾不黑屏 |
| 4K60 HEVC 10bit 硬解 | CPU ≤ 15%（中端 CPU），不掉帧 |
| 弹幕与画面同步误差 | ≤ 50 ms |
| Anime4K "流畅"档 1080p → 4K | 中端独显（RTX 3060 级）不掉帧 |
| 稳定性 | 连续播放 3 小时无崩溃、内存不持续增长；内核异常自动重建，不闪退 |

## 2. 为什么选 mpv

| | 系统 Media Foundation（现状） | FlyleafLib（原方案） | **libmpv（本方案）** |
|---|---|---|---|
| 格式与编码 | 依赖系统扩展，MKV、AV1 等参差不齐 | FFmpeg，全 | FFmpeg，全 |
| ASS 特效字幕 | 不支持 | 部分 | **libass，完整** |
| 画质处理（缩放、去色带、色调映射） | 基本没有 | 有一些 | **libplacebo，业界顶级** |
| Anime4K / 自定义着色器 | 极难（需逐帧拷出再自己实现） | 不支持 | **加载 GLSL 文件即可** |
| 补帧（display-resample） | 无 | 无 | **有** |
| 嵌入 WinUI 3 | 原生 | 原生 SwapChainPanel | mpv ≥ 0.41：`d3d11-output-mode=composition` + `display-swapchain`，挂到 SwapChainPanel |
| 许可 | 系统自带 | LGPL | 常见构建为 GPL（项目改用 GPL-3.0 开源即可） |
| 代价 | — | 纯 C#，可控 | 原生库约 60～100 MB；需要自己写互操作 |

结论：
- 对"高质量、高性能、本地播放、超分"这四项要求，mpv 是唯一四项全满足的选择。
- 已有 WinUI 3 + libmpv 的同构项目可以参考：nami 用的是合成交换链方式，Richasy/mpv-winui 走 OpenGL/ANGLE 转换，已在 Bili.Copilot 中实际使用。

## 3. 架构

```
┌─────────────────────────── PlayerPage (XAML) ───────────────────────────┐
│  控制栏 / 进度条 / 侧边面板 / 提示            ← 现有 UI，基本不动         │
│  DanmakuOverlay（合成表面，透明叠加）         ← 现有，改为订阅 mpv 时钟   │
│  SwapChainPanel  ←  mpv 的 D3D11 合成交换链   ← 新                        │
└──────────────────────────────────────────────────────────────────────────┘
            │ IPlaybackEngine（统一接口）
     ┌──────┴────────┐
 MpvEngine（新，默认）   MediaFoundationEngine（现有，保底回退）
     │
 libmpv-2.dll  ── vo=gpu-next, gpu-context=d3d11, hwdec=d3d11va
     │
 网络片源 → MediaProxy（现有：HLS 去广告、Range 透传）→ 新增分段磁盘缓存
 本地文件 → 直接交给 mpv
```

要点：

- **`IPlaybackEngine` 抽象**：
  - 统一接口：打开、播放、暂停、跳转、倍速、音量、音轨、字幕、属性观察、事件。
  - 播放页只依赖这个接口。
  - 设置里可以切"播放内核：mpv / 系统"。mpv 初始化失败时自动回退到系统内核，保证永远能播。
- **互操作**：
  - 自己写一层薄的 P/Invoke（`LibraryImport`）对接 mpv client API。这套 API 是 C 接口，只有几十个函数，比依赖第三方封装更可控。
  - 事件循环放在独立线程上（`mpv_wait_event`），再派发回 UI 线程。
  - 属性用 `mpv_observe_property` 订阅：`time-pos`、`pause`、`duration`、`demuxer-cache-state`、`track-list`、`video-params` 等，不再靠轮询。
- **交换链**：
  - 交换链在第一次出现 `video-reconfig` 事件后才能拿到，拿到后挂到 SwapChainPanel。
  - 尺寸和 DPI 变化时通知 mpv 重设大小。
  - 显卡丢失时重建交换链。
- **弹幕时钟**：改为直接订阅 mpv 的 `time-pos`，精度更高，暂停、跳转、倍速天然同步。
- **系统媒体控制（SMTC）**：mpv 不自带这一块，改用 `ISystemMediaTransportControlsInterop.GetForWindow(hwnd)` 自己接。功能不倒退：片名、海报、媒体键、上/下一集都保留。

## 4. 功能清单

### 4.1 播放核心（M1，和现有功能对齐）
- 网络片源：HLS 和 MP4 经 MediaProxy 播放，去广告、续播、失败或卡顿时自动换源，全部保留。
- 硬件解码：`hwdec=d3d11va`；遇到不支持的编码自动回退到软件解码，并在信息面板里标明。
- 倍速：0.5–3x，变速不变调（scaletempo2）。
- 续播、进度保存、下一集预告卡片、自动连播。
- 画中画、全屏、快捷键、光标自动隐藏，全部保留。
- **无缝下一集**：剧集最后 30 秒在后台预取下一集的播放列表和第一个分段，切集基本无感。

### 4.2 画质（M2）
- **画质档位**：三个预设，第一次启动时按显卡（DXGI 适配器信息）自动推荐，也可以手动切换。

  | 档位 | 缩放算法 | 去色带 | 其他 |
  |---|---|---|---|
  | 性能 | bilinear | 关 | 适合核显、笔记本省电 |
  | 均衡（默认） | spline36 | 开 | — |
  | 画质 | ewa_lanczossharp | 开 | 高质量色度缩放 |

- **HDR**：支持 HDR10 和 HLG。
  - 显示器开了 HDR 时直通（交换链用 HDR 格式）。
  - 否则做色调映射到 SDR（bt.2390 曲线 + 峰值检测）。
- **补帧 / 运动平滑**（可选开关）：`video-sync=display-resample` + `interpolation`。24 帧电影在高刷新率屏上不抖动。
- **画面调节**：亮度、对比度、饱和度、伽马、锐化。
- **其他**：比例与裁切（原始 / 16:9 / 4:3 / 2.35:1 / 铺满）、缩放平移、旋转、去隔行（自动）。
- **截图**：带不带字幕都可以，保存到「图片\MoonMovie」，同时复制到剪贴板。

### 4.3 超分辨率（M4）
- **动漫：Anime4K**。随包附带官方 GLSL 着色器（MIT 许可），菜单直接选：

  | 选项 | 对应 Anime4K 预设 | 适合 |
  |---|---|---|
  | 关 | — | — |
  | 流畅 | Mode A（Fast） | 中端独显 |
  | 高质量 | Mode A（HQ） | 高端独显 |
  | 针对低清 | Mode B / C | 480p、720p 老番 |

- **真人：FSRCNNX 或 ArtCNN**（可选下载包，不占安装体积）。
- **N 卡 RTX 视频超分（RTX VSR）**：mpv 的 `d3d11vpp` 可以调用，需要实测验证后再开放。
- **自动判断**：只在片源分辨率低于屏幕时启用。信息面板显示"超分：Anime4K 流畅 · 1080p → 4K"。
- **性能保护**：检测到连续掉帧时自动降一档，并给出提示。

### 4.4 字幕（M2）
- **格式**：内嵌字幕轨（ASS、SRT、PGS 图形字幕）、外挂字幕（同名 `.ass` / `.srt` / `.sup` 自动加载，也可以拖进窗口）。
- **ASS 特效**：完整渲染（libass），番剧字幕组的特效、字体、定位都能正确显示。
- **双字幕**：主字幕 + 次字幕，比如中文和英文同时显示。
- **样式**：字号、位置、描边或背景板、颜色；ASS 字幕可以选"保留原样式 / 强制统一样式"。
- **字幕时间轴校准**：±0.1 s 微调，按片记忆。
- **在线字幕搜索**（后续）：本地片没有字幕时，按文件名或片名搜索下载（如 assrt / OpenSubtitles，需要用户自己的 Key）。

### 4.5 音频（M2）
- 音轨切换，适用于多语言和评论音轨。
- 音量最高可以放大到 150%。
- **夜间模式**：动态范围压缩，深夜对白清楚、爆炸声不吓人。
- 音画同步微调，按片记忆。
- 选择输出设备（耳机 / 音箱 / HDMI），可选杜比和 DTS 源码输出到功放。

### 4.6 播放器交互升级（M2）
- **侧边面板新增「画面」「声音」「字幕」三个标签**，和现有的选集、片源、弹幕并列，所有调节都实时生效。
- **信息面板**（快捷键 I），显示：
  - 分辨率和编码；
  - 硬解或软解；
  - 码率、丢帧数；
  - 缓冲时长；
  - 超分状态；
  - 片源延迟。
- **进度条缩略图预览**：本地文件和已缓存的分段，鼠标悬停显示画面。由后台一个无窗口的 mpv 实例生成，并做缓存。
- **章节**：进度条上显示章节刻度；可以跳过片头片尾，按剧集记忆片头时长，第二集起自动跳过。
- **A-B 循环、逐帧前进 / 后退**（`,` `.`）。
- **新增快捷键**（沿用 mpv 习惯）：

  | 按键 | 功能 |
  |---|---|
  | `I` | 信息面板 |
  | `V` | 字幕开关 |
  | `Shift+V` | 切换字幕轨 |
  | `A` | 切换音轨 |
  | `Ctrl+S` | 截图 |
  | `Z` / `X` | 字幕提前 / 延后 |

### 4.7 本地播放（M3）
- **打开方式**：
  - 「打开文件 / 文件夹」按钮；
  - 拖文件进窗口直接播放；
  - 命令行参数，为以后关联"打开方式"做准备，打成 MSIX 包后就可以声明文件关联。
- **本地媒体库**（媒体库新增「本地」标签）：
  - 添加监视文件夹，自动扫描，文件变化实时更新。
  - **文件名识别**：
    - 支持的写法：`S01E02`、`第2集`、`[字幕组] 片名 - 03 [1080p]`、`片名.2019.1080p.BluRay`。
    - 解析出片名、季、集、年份后匹配 TMDB，自动配上海报、背景图、简介。
    - 匹配错了可以手动改，改动会被记住。
  - **剧集整理**：同一部剧的文件归为一部，按季、集排序，和在线剧集用同一套详情页、选集面板。
- **和现有功能打通**：
  - 观看进度、继续观看、历史记录统一管理，本地和在线的条目一起显示；
  - 弹幕：本地片也能按识别出的片名和集数自动匹配弹幕。
- **支持的格式**：mkv、mp4、avi、ts、m2ts、flv、webm、rmvb 等，以及蓝光、DVD 目录（BDMV / VIDEO_TS）。

### 4.8 缓存与离线（M5）
- **片源匹配缓存**：记住"这部作品在哪个站有、哪个最快"，下次打开详情页立刻出结果，后台再刷新。
- **分段磁盘缓存**：MediaProxy 把拉过的分段写进磁盘做 LRU 缓存，上限可以设置，默认 5 GB。回看和往回拖都是秒开。
- **离线下载**：
  - 可以"下载本集 / 整季"，后台并发拉取全部分段（去广告后的版本），合成一个本地文件；
  - 下载完的在本地媒体库里显示，断网也能看；
  - 下载管理页：进度、暂停、续传、限速、删除。

### 4.9 系统集成
- SMTC（媒体浮层、媒体键）：用 interop 方式重新接上，功能不倒退。
- 播放时不熄屏，已经有了。
- 任务栏缩略图按钮：播放/暂停、上一集、下一集；任务栏图标上显示播放进度。
- 打成 MSIX 包后再做：文件关联、"继续观看"跳转列表。

## 5. 性能策略

- 默认开硬件解码；软解只作回退。解码以后的帧留在显卡里，零拷贝送到 libplacebo 渲染。
- 网络缓冲：
  - 预读 `demuxer-readahead-secs=30`；
  - 前向缓存上限约 400 MB，后向约 100 MB，往回拖几分钟也不需要重新下载；
  - 断线自动重连：`stream-lavf-o=reconnect=1,reconnect_streamed=1`。
- 首帧优化：
  - 片源测速时顺便预取播放列表；
  - 点"播放"时 MediaProxy 已经拿到第一个分段；
  - 打开时用 `--start=` 直接从续播位置开始，避免"先播开头再跳过去"。
- 下一集：在 mpv 播放列表里预先加入下一集，配合 `prefetch-playlist=yes`。
- 弹幕和界面都不占用渲染线程。mpv 自己的渲染线程负责呈现，界面卡顿不会影响画面流畅度。
- 档位自动降级：根据 `frame-drop-count`、`vo-delayed-frame-count` 判断，连续掉帧时自动降档并提示。

## 6. 里程碑

| 阶段 | 内容 | 预计 |
|---|---|---|
| **M0 技术验证** | 接入 libmpv，交换链挂上 SwapChainPanel；弹幕和控制栏叠加；通过 MediaProxy 播放 HLS；缩放、全屏、画中画下画面正常 | 1–2 天 |
| **M1 功能对齐** | `IPlaybackEngine` + MpvEngine；现有播放页全部功能迁移；SMTC 重新接入；保留回退内核 | 3–4 天 |
| **M2 画质 / 字幕 / 音频 / 交互** | 画质档位、HDR、补帧、截图；字幕全套；音频全套；画面、声音、字幕面板；信息面板；章节和跳过片头 | 3–4 天 |
| **M3 本地播放** | 打开文件、拖放、本地媒体库扫描与识别、TMDB 匹配、进度打通、本地弹幕 | 3–4 天 |
| **M4 超分** | Anime4K 预设、自动判断与降级、真人超分可选包、RTX VSR 验证 | 2 天 |
| **M5 缓存与离线** | 片源匹配缓存、分段磁盘缓存、离线下载与管理页 | 3 天 |
| **M6 打包发布** | MSIX、自签名证书与一键安装、GitHub Actions 自动发布、任务栏集成、文件关联 | 1–2 天 |

每个阶段结束都能用，可以单独发版。顺序可以调整，比如 M3 本地播放提前到 M2 之前。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 合成交换链方式依赖 mpv ≥ 0.41，各家构建版本不一 | M0 锁定一个已验证的 libmpv 构建，随包分发，不依赖用户系统里的 mpv |
| 交换链在缩放、DPI 变化、显卡重置时出问题 | M0 专门测试这些场景；准备 OpenGL/ANGLE 转换路线（Richasy 方案）作为备选 |
| HDR 在合成模式下的表现 | 先保证 SDR 和色调映射正确；HDR 直通单列验证项 |
| 包体积增加约 60–100 MB | 着色器、真人超分模型做成可选下载；用精简构建（去掉不需要的 FFmpeg 组件） |
| GPL 许可 | 项目以 GPL-3.0 开源，README 写明依赖许可 |
| 少数显卡驱动兼容问题 | 保留系统内核作为回退，设置里可以手动切换；崩溃时自动重建内核实例 |

## 8. 需要你确认的事

1. 内核换成 mpv，项目以 **GPL-3.0** 开源，可以吗？
2. 里程碑顺序：建议按 M0 → M1 → M3（本地）→ M2 → M4 → M5 → M6，先把"本地能放"尽早做出来。还是更想先要画质和字幕（M2）？
3. 离线下载的默认缓存上限（建议 5 GB）和下载目录（建议放「视频\MoonMovie」）。
